# Admin Seeder

## Esta funcion se usa para tener una base osea que muestra una creacion de datos de ejemplo los cuales son los 2 casos que nos pidio el profe

### - Se usa para poner ejemplos en la DB de migrate

## Parametros

### - nombre_completo

### - username

### - password(esta hasheada con Hash::make y nunca se manda por texto plano)

### - activo

## Favor de leer lo siguiente

### - Si llega a fallar puede ser que los atributos anteriormente mencionados hayan cambiado asegurate de verificar los nombres y cantidad

### - Para ejecutar el seed se necesita php artisan db:seed --class=AdministradorSeeder

### - Si nombre es cambiado del seed solo se tiene que cambiar el --class={nombre del seed}
